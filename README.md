# Midnight_moon — Турбаза на горном алтае 

🔗 **Сайт проекта:** https://midnight-moon.vercel.app/

На бэке реализована отправка сообщений в бота и на личную почту
---

## Роли в проекте
Это групповой проект, в рамках которого обязанности были распределены следующим образом:
* **Лев(я):** Разработка и деплой бэкенда (FastAPI), настройка интеграций с Telegram Bot API и Gmail SMTP, логика на js.
* **Никита:** Разработка визуального интерфейса и верстка, подбор цветовой палитры.

---

## 🛠 Стек

### Frontend:
* **HTML5 / CSS3 / JavaScript** — адаптивный и быстрый интерфейс.
* **Хостинг:** [Vercel](https://vercel.com).

### Backend:
* **Python 3.11+ / FastAPI** — база быстрого бэкэнда.
* **Pydantic** — валидация входящих данных формы.
* **Httpx** — асинхронные запросы к Telegram Bot API.
* **Smtplib / Email.mime** — отправка уведомлений на почту через Gmail SMTP.
* **Хостинг:** [Render](https://render.com).

---

## 🚀 Функционал
**Форма брони:** Пользователь выбирает домик, даты и оставляет контактные данные.
**Telegram-алерт:** При успешной отправке заявки бот пересылает сообщение в личный чат.
**Email-уведомления:** Параллельно с помощью `BackgroundTasks` на почту отеля уходит подробная информация о бронировании.
**Отказоустойчивость:** Ошибки валидации и сетевые сбои логируются на сервере, предотвращая падение приложения.

## ⚙️ Локальный запуск и установка зависимостей

### Клонирование репозитория:
```bash
git clone https://github.com/levmamatov/Midnight_Moon.git
cd Midnight_Moon/backend
```
### Создание виртуального окружения:
Для Windows:
```bash
python -m venv venv
venv\Scripts\activate
```
Для macOS / Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```
### Зависимости
```bash
pip install --upgrade pip
pip install -r requirements.txt
```
### Переменные окружения
Для них создайте .env в папке back с переменными 
```bash
TG_BOT_TOKEN = токен вашего бота который появляется при создании
TG_CHAT_ID = ваш личный чат ID чтобы бот понимал кому писать, получить можно через @userinfobot (нажмите в своём боте /start)
SMTP_USER = ваша логин для подключения к серверу вашей почты (можно указать тот же что и в EMAIL_TO)
SMTP_PASSWORD = (в случае .gmail) перед созданием пароля включите двухфактору, зайдите в Безопастность -> Пароли приложений и скопируйте пароль без пробелов.
EMAIL_TO = почта-получатель писем
```
### Запуск сервера
```bash
uvicorn main:app --reload
```
